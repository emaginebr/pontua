1. Carregando (LoadingState)

Skeleton com a forma do conteúdo, exibido após 300 ms; aria-busy + "Carregando…" oculto. Sem brilho animado com movimento reduzido.

2. Erro ao carregar (ErrorState)

Mensagem da API ou genérica + "Tentar de novo". role="alert".

3. Sem conexão em tela de leitura (StaleDataNotice + ações desabilitadas)

Dados do cache com "dados de [data/hora]"; ações que exigem servidor ficam visíveis, desabilitadas e explicadas ("Disponível com conexão").

4. Nova versão (UpdatePrompt) e conexão restabelecida

Cartão acima da barra inferior (celular) / canto inferior esquerdo do conteúdo (computador). Não rouba o foco.

5. Instalar no iPhone (folha com instruções)

iOS não tem prompt nativo: passos numerados com os ícones do Safari.

6. Sem permissão e sincronização concluída

Rota sem permissão volta para o Ponto com toast "Você não tem acesso a esta área.". Fila enviada: toast de sucesso.
